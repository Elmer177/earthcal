# のび太くんの告白のうわさは、昼休みにどこまで広がるか
数値地球惑星科学の発表課題

Daley–Kendall 模型を拡張した常微分方程式で、うわさがクラスに広がる様子を4次Runge–Kutta法（RK4）で解く。


## 設定
- クラスメイト 30人（S(0) = 30）、時間は 0〜50分（昼休み）
- 50分の時点で、真実を知る人 K = 30 − S が15人以上いたら、のび太くんは早退する
- RK4、刻み幅 h = 0.1分（500ステップ）

## モデル
| 版 | 内容 | パラメータ | 解析解 |
|---|---|---|---|
| [v1](v1/) | しずかちゃんが話し続ける | β | あり |
| [v2](v2/) | しずかちゃんが飽きる | β, γ | 最終値のみ |
| [v3](v3/) | 聞いた人も広める（DK模型） | β, γ | 最終値のみ |
| v4 | 真実とデマに分かれる | ε, β_F | なし（作成中） |
| v5 | 目撃者がLINEに投稿する | δ0, τ | なし（予定） |

式の詳細は [HANDOFF.md](HANDOFF.md) を参照。

## 実行方法
```sh

./v1             # v1_*.dat ができる
gnuplot v1.gp    # v1.png ができる
```
v2、v3 も同じ手順で実行できる。
